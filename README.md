# Wedsite-Th-ng-m-i-i-n-t-VietCraft-B-t-Tr-ng
Dự án xây dựng nền tảng Thương mại điện tử VietCraft Bát Tràng. Hệ thống cung cấp giải pháp liên kết các xưởng gốm truyền thống, giải quyết bài toán phân phối bán lẻ (B2C), quà tặng doanh nghiệp (B2B) và tích hợp quản lý đặt lịch tour trải nghiệm thực tế (O2O).
